供應商

連線到任何 OpenAI 相容的 /chat/completions 服務。API Key 在伺服器端加密保存，不會回傳到瀏覽器；自建模型可以不填 Key。

沒有內建供應商：可在下方新增，或由部署者用 PROVIDER_N_* 環境變數設定（唯讀顯示）。新增後請到「一般」選擇預設模型。

只允許公開 HTTPS 位址。localhost、私有 IP、.local、.internal 會被拒絕。

語意檢索（嵌入模型）

選一個提供 /embeddings 的供應商（例如 OpenAI 的 text-embedding-3-small）。知識庫會同時用關鍵字與語意找段落。未設定時只用關鍵字檢索。

關鍵字檢索

「自動」在資料庫支援時用中文斷詞＋BM25 排序（Neon Lakebase Search），沒有結果或出錯時退回二字組比對；也可固定只用其中一種。

網頁搜尋

輸入框「搜尋」開啟時，伺服器先用這裡的服務搜尋，再把摘要交給模型。Key 加密存在資料庫；用完額度時貼上新 Key 儲存即可，不用重新部署。

MCP 工具

連接遠端 MCP 伺服器（Streamable HTTP，需 HTTPS）。模型想用工具時會先在對話中顯示工具與參數，你按「允許」才會執行。Token 加密存在資料庫。本機（stdio）類 MCP 無法在 Netlify 上執行。
